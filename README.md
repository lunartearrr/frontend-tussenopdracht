# Frontend Tussenopdracht
Wireframe nabouwen met semantische HTML en CSS flexbox, gemaakt voor het vak Kennis Create and Code aan Hogeschool Rotterdam.

## Over de opdracht
Ik heb als website gekozen voor een webshop waar je aroma diffusers, kaarsen en dergelijke kunt kopen. Het design/thema zou in principe ook gebruikt kunnen worden voor andere soorten webshops die vergelijkbare producten verkopen.

## Gebruikte technieken
- Semantische HTML-structuur
- CSS Flexbox voor layout

## Bestandsstructuur
- `index.html`
- `css/style.css`
- `assets/images/`
